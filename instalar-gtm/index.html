Instalar o Google Tag Manager no site

Siga os passos abaixo para instalar o GTM no seu site. O ID do seu contêiner é esse aqui:

ID do contêiner
GTM-NDPCSCS
Códigos para instalar

Os dois snippets que precisam ir no site

Você vai precisar colar dois trechos de código no site. Um vai no <head> e o outro logo após o <body>. Veja abaixo o passo a passo para o seu tipo de site.

1
Código do <head>
Cole no <head> da página 
<!-- Google Tag Manager -->
<script>(function(w,d,s,l,i){w[l]=w[l]||[];w[l].push({'gtm.start':
new Date().getTime(),event:'gtm.js'});var f=d.getElementsByTagName(s)[0],
j=d.createElement(s),dl=l!='dataLayer'?'&l='+l:'';j.async=true;j.src=
'https://www.googletagmanager.com/gtm.js?id='+i+dl;f.parentNode.insertBefore(j,f);
})(window,document,'script','dataLayer','GTM-NDPCSCS');</script>
<!-- End Google Tag Manager -->
2
Código do <body>
Cole logo após <body> 
<!-- Google Tag Manager (noscript) -->
<noscript><iframe src="https://www.googletagmanager.com/ns.html?id=GTM-NDPCSCS"
height="0" width="0" style="display:none;visibility:hidden"></iframe></noscript>
<!-- End Google Tag Manager (noscript) -->
Passo a passo

Como instalar no seu tipo de site

Selecione abaixo a plataforma do seu site para ver as instruções específicas.

1

Instale o plugin GTM4WP

No painel do WordPress, vá em Plugins e busque por GTM4WP (Google Tag Manager for WordPress). Instale e ative.

Plugins › Adicionar novo › buscar "GTM4WP"
2

Abra as configurações do plugin

Depois de ativar, vá no menu lateral do WordPress:

Configurações › Google Tag Manager
3

Cole o ID do contêiner

No campo "Google Tag Manager ID", cole o ID do seu contêiner:

GTM-NDPCSCS
Dica: Use o botão "Copiar ID" lá no topo desta página para copiar o ID certo.
4

Salve as alterações

Clique em "Salvar alterações" no final da página. O plugin vai instalar os dois snippets automaticamente no lugar certo.

5

Avise a gente

Depois de salvar, manda mensagem pra gente confirmar que o GTM está funcionando no site.

Prefere não usar plugin? Se o seu tema tiver um campo de "Scripts no head", você pode colar os dois códigos diretamente lá em Aparência → Personalizar → HTML adicional. Mas o plugin é mais seguro e mais fácil de atualizar depois.
1

Acesse o Custom Code do Elementor

No painel do WordPress, vá no menu do Elementor:

Elementor › Custom Code
2

Crie o código do <head>

Clique em "Adicionar Novo". Dê o nome GTM Head, cole o Código 1 (o do head) no editor, e em Location selecione "Head". Clique em Publicar.

3

Crie o código do <body>

Clique novamente em "Adicionar Novo". Dê o nome GTM Body, cole o Código 2 (o do body/noscript) no editor, e em Location selecione "Body - Start". Clique em Publicar.

4

Confirme que os dois estão ativos

Na lista do Custom Code, os dois devem aparecer com status Publicado. Se algum aparecer como rascunho, clique nele e publique.

5

Avise a gente

Depois de publicar os dois, manda mensagem pra gente confirmar que o GTM está funcionando no site.

Elementor Pro (versão paga) tem o Custom Code nativo. Se você usa o Elementor gratuito, vai precisar de um plugin separado para injetar scripts, como o Insert Headers and Footers, ou usar o método do WordPress com GTM4WP.

Sites construídos com ferramentas de IA (como Lovable, Bolt, Framer, Claude e outras) costumam ter uma seção de configurações onde você pode adicionar código personalizado no head do site. O processo geral é:

1

Abra as configurações do site

Dentro da ferramenta que você usa, procure por Configurações, Settings ou SEO. Costuma ficar num ícone de engrenagem ou no menu principal.

2

Encontre a seção de código personalizado

Procure por campos como "Custom Code", "Head Code", "Scripts" ou "HTML personalizado". Pode estar dentro de uma aba de SEO ou Avançado.

3

Cole o Código 1 no campo do <head>

Se a ferramenta tiver um campo específico para o <head>, cole lá o Código 1. Se tiver só um campo geral, cole os dois códigos juntos, com o Código 1 primeiro.

4

Cole o Código 2 no campo do <body>

Se houver um campo separado para código logo após o <body>, cole o Código 2 lá. Esse campo pode aparecer como "Body Start" ou "After body tag".

Não encontrou o campo? Manda um print das configurações do seu site pra gente. A gente te ajuda a identificar onde colar.
5

Publique e avise a gente

Salve as configurações e publique o site. Depois manda mensagem pra gente confirmar que o GTM está instalado corretamente.

Ficou alguma duvida?

Manda mensagem pra gente. Se preferir, tira um print da tela onde travou e a gente resolve.
